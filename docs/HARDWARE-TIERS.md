# 硬件分级：从 24 GB 到 8 GB、再到没有独显

这套东西是**两个模型**（一个说话、一个听话），所以要看的不是"能不能跑"，而是"能让几个同时待在显存里"。

## 显存占用是怎么算的

> 以下为 **v0.6.0 默认档（两个 0.6B）** 的实测值；早期 1.7B ASR + CosyVoice2 的组合约需 10 GB。

| 组件 | 模型 | 常驻显存（实测） | 一句话的开销 |
| --- | --- | --- | --- |
| TTS（说话） | Qwen3-TTS-**0.6B** | 单实例 **≈ 2.3 GB**；`gpu2` 双实例 **≈ 4.6 GB** | 首次加载 ≈12 s；之后 1–3 s/句 |
| ASR（听话） | Qwen3-ASR-**0.6B** | **≈ 2.3 GB** | 首次加载 ≈2 s；RTF≈0.11（56 s 音频 → 6 s） |
| 合计（两个都常驻） | — | **约 4.6 GB** | — |

**结论：8 GB 显卡可以全套常驻**（约 4.6 GB + 系统/桌面 2 GB 左右，仍有余量）。
12 GB 以上更从容：可以开 `gpu2` 双实例并行（合计约 6.9 GB），长文连发更快。

> 注意：**"还剩 14 GB 也算 OOM"** 是真的会发生的——ComfyUI 之类的应用占着显存时，模型分配再小也会失败。跑这套之前先把别的大模型应用关掉或让它卸载模型。

## 按显存选方案

| 你的显存 | 能跑什么 | 建议 |
| --- | --- | --- |
| **≥ 12 GB**（3060 12G / 4070 / 4080 / 5090 等） | 全套常驻 + 可开 `gpu2` 双实例 | 默认安装即可，档位选 `gpu2`，长文连发更快 |
| **8 GB**（3060Ti / 4060 / 3070 等） | **全套常驻没问题**（≈4.6 GB） | 档位选 `gpu` 单实例；显存紧张就把「驻留方式」改成空闲卸载 |
| **6 GB**（2060 / 1660 等） | 全套勉强，建议只留一个常驻 | TTS 或 ASR 二选一常驻，另一个用空闲卸载轮换 |
| **≤ 4 GB / 核显 / 无独显** | 只能 CPU 推理 | 档位选 `cpu`（CosyVoice2），能跑但很慢，适合"先听个响" |
| **AMD 显卡 / Apple Silicon** | 本包**不支持**（Windows + CUDA 轮子） | 需要自行换 ROCm / MPS 版 torch，属于另一套改造 |

## 8 GB 怎么跑（已经不用做取舍，留个说明）

1. **默认就行**：两个 0.6B 合计 ≈4.6 GB，`gpu` 档直接全套常驻；
2. **想再省**：面板里把 TTS / ASR 的「驻留方式」改成空闲卸载，不用的时候自动让出显存；
3. **要和别的 AI 应用共存**：先把对方模型卸掉（ComfyUI 之类），再起这套；显存不够时优先把 TTS 切到 `cpu` 档。

## CPU 推理大概什么速度

**没有实测数据，别把下面的当结论**——只是量级提示：CosyVoice2-0.5B 在桌面 CPU 上通常是"实时率的数倍耗时"，一句 10 秒的话要几十秒；Qwen3-ASR-1.7B 的 CPU 转写同样比 GPU 慢一个数量级以上。真的要长期用，建议至少 8 GB 显存的 NVIDIA 卡。

## 磁盘与内存

| 项 | 需求 | 说明 |
| --- | --- | --- |
| 磁盘 | **约 20 GB**（安装期峰值约 25 GB） | 两个 venv 各 ≈5.5 GB（torch 占大头）+ 两个模型 ≈8.2 GB + 源码与缓存 |
| 内存 | **16 GB 起**，8 GB 会非常紧 | 加载权重峰值约 10 GB |
| 系统 | Windows 10 / 11 x64 | 脚本是 PowerShell + `.cmd` |
| Python | 3.12（3.11 可试） | 两个 venv 都由它创建 |
| ffmpeg | 任意近期版本，在 PATH 里 | wav ↔ mp3、任意音频转 16 kHz |
| 显卡驱动 | 支持 CUDA 12.8（RTX 50 系必须） | 40 系及更早可以用 cu121 轮子 |

## 显存/算力版本对照（选 torch 轮子用）

| 显卡 | 算力 | 需要的 torch 轮子 |
| --- | --- | --- |
| RTX 50 系（5090 / 5080 / 5070） | sm_120 | **cu128**（用 cu121 会报 `no kernel image is available`） |
| RTX 40 系 | sm_89 | cu121 或 cu128 均可 |
| RTX 30 系 | sm_86 | cu121 或 cu128 均可 |
| RTX 20 系 / GTX 16 系 | sm_75 | cu121 |
| 无独显 | — | CPU 轮子（`--index-url https://download.pytorch.org/whl/cpu`） |

## 一句话结论

- **12 GB 以上**：最舒服，全套都能跑；
- **8 GB**：能跑，但要在"说话"和"听话"里选一个常驻；
- **没有独显**：能跑通、能听个响，但别指望流畅对话。
