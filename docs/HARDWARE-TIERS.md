# 硬件分级：从 24 GB 到 8 GB、再到没有独显

这套东西是**两个模型**（一个说话、一个听话），所以要看的不是"能不能跑"，而是"能让几个同时待在显存里"。

## 显存占用是怎么算的

| 组件 | 模型 | 常驻显存（实测） | 一句话的开销 |
| --- | --- | --- | --- |
| TTS（说话） | CosyVoice2-**0.5B** | 约 **2.5–3.5 GB** | 首次加载 ≈15 s；之后 1–3 s/句 |
| ASR（听话） | Qwen3-ASR-**1.7B** | 约 **6.5 GB**（峰值） | 首次加载 ≈3 s；RTF≈0.11（56 s 音频 → 6 s） |
| 合计（两个都常驻） | — | **约 10 GB** | — |

以上是本机（RTX 5090 Laptop 24 GB）实测：两个服务同时常驻时 `nvidia-smi` 显示 10.3 GB（含系统与桌面占用约 2.4 GB）。

> 注意：**"还剩 14 GB 也算 OOM"** 是真的会发生的——ComfyUI 之类的应用占着显存时，CosyVoice 分配 18 MB 都会失败。跑这套之前先把别的大模型应用关掉或让它卸载模型。

## 按显存选方案

| 你的显存 | 能跑什么 | 建议 |
| --- | --- | --- |
| **≥ 16 GB**（4080 / 4090 / 5080 / 5090 等） | 全套常驻，说话+听话都行 | 默认安装即可 |
| **12 GB**（3060 12G / 4070 等） | 全套**勉强**常驻（10 GB 模型 + 系统占用） | 关掉浏览器硬件加速、关掉其它 AI 应用；仍 OOM 就取消 ASR |
| **8 GB**（3060Ti / 4060 / 3070 等） | **只能常驻一个** | 推荐**只跑 TTS**（3 GB 左右，最稳），ASR 用 CPU 版或不开 |
| **6 GB**（2060 / 1660 等） | 只跑 TTS，且要留余量 | TTS 单跑；`fp16` 打开；句子别太长 |
| **≤ 4 GB / 核显 / 无独显** | 只能 CPU 推理 | 能跑但很慢（见下），适合"先听个响" |
| **AMD 显卡 / Apple Silicon** | 本包**不支持**（Windows + CUDA 轮子） | 需要自行换 ROCm / MPS 版 torch，属于另一套改造 |

## 8 GB 怎么跑（三条路）

1. **只要"它说话"**：不启动 ASR 服务，只跑 TTS。`verify.ps1` 里 asr 那两项会 FAIL，用 `/say` 单测即可。
2. **要"它听话"**：给 ASR 装 CPU 版 torch（`pip install torch --index-url https://download.pytorch.org/whl/cpu`），转写比 GPU 慢一个量级，但能用。
3. **两个都要、但不同时**：先让 ASR 跑完转写 → 停掉 ASR 服务 → 再起 TTS。本包没有自动调度，需要手动 `scripts\restart-guards.ps1` 或直接杀端口进程。

## CPU 推理大概什么速度

**没有实测数据，别把下面的当结论**——只是量级提示：CosyVoice2-0.5B 在桌面 CPU 上通常是"实时率的数倍耗时"，一句 10 秒的话要几十秒；Qwen3-ASR-1.7B 的 CPU 转写同样比 GPU 慢一个数量级以上。真的要长期用，建议至少 8 GB 显存的 NVIDIA 卡。

## 磁盘与内存

| 项 | 需求 | 说明 |
| --- | --- | --- |
| 磁盘 | **约 20 GB**（安装期峰值约 25 GB） | 两个 venv 各 ≈5.5 GB（torch 占大头）+ 两个模型 ≈8.2 GB + 源码与缓存 |
| 内存 | **16 GB 起**，8 GB 会非常紧 | 加载权重峰值约 10 GB |
| 系统 | Windows 10 / 11 x64 | 脚本是 PowerShell + `.cmd` |
| Python | 3.12（3.11 可试） | 两个 venv 都由它创建 |
| ffmpeg | 任意近期版本，在 PATH 里 | wav ↔ mp3、任意音频转 16 kHz |
| 显卡驱动 | 支持 CUDA 12.8（RTX 50 系必须） | 40 系及更早可以用 cu121 轮子 |

## 显存/算力版本对照（选 torch 轮子用）

| 显卡 | 算力 | 需要的 torch 轮子 |
| --- | --- | --- |
| RTX 50 系（5090 / 5080 / 5070） | sm_120 | **cu128**（用 cu121 会报 `no kernel image is available`） |
| RTX 40 系 | sm_89 | cu121 或 cu128 均可 |
| RTX 30 系 | sm_86 | cu121 或 cu128 均可 |
| RTX 20 系 / GTX 16 系 | sm_75 | cu121 |
| 无独显 | — | CPU 轮子（`--index-url https://download.pytorch.org/whl/cpu`） |

## 一句话结论

- **12 GB 以上**：最舒服，全套都能跑；
- **8 GB**：能跑，但要在"说话"和"听话"里选一个常驻；
- **没有独显**：能跑通、能听个响，但别指望流畅对话。
