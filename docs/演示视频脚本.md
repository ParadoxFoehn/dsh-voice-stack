# 演示视频脚本（v0.6.0）

> 用途：B 站/抖音发布的功能演示。目标时长 **4–6 分钟**。
> 录制方式约定：**开场效果展示由作者本人录屏**（真实使用），其余分段按下面清单录，旁白可交本机 TTS 念。
> 画面标注 `【录】` 的段落需要你动手；`【剪】` 是需要插入的素材（截图/字幕卡）。

## 0. 开场 · 效果展示（0:00–0:25）【你的素材】

**目的**：前 3 秒就让人听到"它真的在说话"，不要从安装讲起。

| 画面 | 说明 |
| --- | --- |
| 电话悬浮条亮起 → 点绿电话按钮 | 特写，光标停留 1 秒 |
| 你说话 → 转写文字出现在会话里 | 保留输入条与气泡 |
| 它开口回答（波形/气泡） | 声音要清楚，字幕跟上 |
| 你中途点「打断」→ 它立刻停 | 这一下最有说服力，别剪掉 |

旁白（可后配）：

> 这是跑在你自己电脑上的 AI 语音，说话、听话都不出本机。

## 1. 它是什么（0:25–0:55）

`【剪】` 标题卡：**小肥鱼会说话了 · v0.6.0**

旁白：

> 两个能力：语音消息——你录一段发出去，它听得懂、也用语音回；
> 语音电话——点一下拨号，你说一句它答一句，随时能打断。
> 模型全在本机跑：说话用 Qwen3-TTS 0.6B，听话用 Qwen3-ASR 0.6B。

## 2. 环境与模型（0:55–1:30）

`【录】` 任务管理器 → 性能 → GPU，指一下显存；再指 `D:\py-tts`、`D:\py-asr` 两个目录。

| 要点 | 口播数字 |
| --- | --- |
| 系统 | Windows 10/11 + NVIDIA 显卡 |
| 显存 | **8 GB 就能全套跑**（两个 0.6B 合计约 4.6 GB），12 GB 以上更从容 |
| 磁盘 | 两个 Python 环境 + 模型，约 14 GB |
| 首次启动 | 加载模型十几秒，之后一句 1–3 秒 |

旁白：

> 显存不用很夸张：两个 0.6B 模型加起来四点多 G，八 G 的卡就能全套常驻。
> 十二 G 以上可以开双实例，长文连发更快。

## 3. 语音服务：启动与设置（1:30–2:30）

`【录】` 悬浮条 → 右键状态灯 → 启动语音服务 → 绿灯；再点齿轮开设置面板。

| 镜头 | 操作 | 说明 |
| --- | --- | --- |
| A | 右键「语音服务」→ 启动 | 首次要等模型加载，状态变绿 |
| B | 点齿轮 → 面板居中弹出 | 面板位置正常（v0.6.0 修好的） |
| C | 切「运行位置」：GPU · Qwen3-TTS ↔ GPU×2 · 双 Qwen3 | 双实例=并行合成长文更快，代价是多占 2.3 G |
| D | 切「驻留方式」：常驻 ↔ 空闲卸载 | 空闲卸载=不发声 N 秒后把模型卸掉，显存归还 |
| E | 底部「预计占用」读数 | 让它出镜，观众能对上自己显卡 |

旁白：

> 服务是插件托管的，关插件它就跟着退，不会留在后台占显存。
> 常驻就是一直待命，一秒出声；空闲卸载更省显存，代价是下次要重新加载。

## 4. 语音消息（2:30–3:20）

`【录】` 输入框左侧声波按钮 → 说一句话 → 待发托盘 → 发送 → 气泡播放器 → 点重听。

| 镜头 | 操作 |
| --- | --- |
| A | 点声波按钮，说"帮我记一下：明天下午三点开会" |
| B | 转写结果出现在托盘里，可试听、可删 |
| C | 点发送 → 会话里出现语音气泡（原生播放器） |
| D | 点播放重听；再点一次从头 |

旁白：

> 录音上限 30 秒，一次最多攒三条。
> 发出去之后是普通消息气泡，能重听、能删，跟聊天里的语音一样。

## 5. 语音电话（3:20–5:00）★ 重点段

`【录】` 完整走一遍：拨号 → 开场白 → 正常问答 → 忙线 → 打断 → 挂断。

| 阶段 | 画面 | 旁白要点 |
| --- | --- | --- |
| 启动 | 点绿色电话按钮，状态「准备中」→ 3 秒后「聆听」 | 接通后 3 秒是准备时间，它在等你说 |
| 空闲 | 绿灯「聆听」，麦克风在采集 | 只有它在等你说话时才亮绿；它正在想或正在说时是黄「忙线」 |
| 忙线 | 让它背一段长文，黄灯「忙线」 | 播报期间麦克风是关的（半双工），你说的话会排不进 |
| 中断 | 播到一半点「打断」 | 立刻静音，而且**不会**又把刚才那段从头念一遍 |
| 挂断 | 点红色挂断 | 回合结束，之后要用文字继续 |

旁白（可拆两段）：

> 半双工是刻意的：它说的时候不听，听的时候不说，不会互相打断。
> 想插话就点打断——这是你要夺回话语权的唯一按钮。
